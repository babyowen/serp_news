## 评分与摘要的来源地域上下文

仅「江苏机关事务」下、来源为极致了 API 且微信长链接的 biz 对应启用注册账号的文章，向评分和摘要请求独立附加发布账号、辖区和层级；若行内有 ghid 或文章身份，必须与链接和注册表一致。名称不参与身份匹配，宁波停用号不生效。市级辖区含所属省份，直辖市和自治区明确标注，国管局只标注中央机关、国家级。

正文明确讲述发布机构本级事务时，可据来源补足「本省／全省／市局」等指代；正文明确地点优先，转载或外地案例不套用来源辖区，指代含糊时不猜测。主关键词、检索词、标题和正文保持原样，数据库无需增列。摘要读取数据库实际保留行的来源和链接，500 字以内仍直接保存原文，已有摘要不重写。

官微评分完成判定及增量、日期复审、普通单关键词、批量和显式重评入口均核对来源上下文指纹；旧的无上下文评分、上下文变化或可信身份失效会重新评分，身份失效后的新结果清除旧指纹。普通来源和其他关键词继续使用原有缓存与模型消息。该规则只提供可信输入与提示约束，不构成生成结果的逐句地域事实校验。
