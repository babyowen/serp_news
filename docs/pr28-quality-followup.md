# PR #28 正文、日期与摘要归因修复

范围：2026-10-07 次晨评估确认的前三项小修复。主事件七天规则不变；不修复历史数据库记录、不自动重评/重做摘要、不增加模型审核调用。

## 正文质量

`content_quality.py` 在评分和写库边界用同一套本地规则识别：纯反馈控件、明确错误页、纯导航、带明确剩余全文标志的付费墙导语、长标题复写。没有添加通用最短字数门槛；有效短公告及正文中提到网站错误/订阅的新闻继续可评分。

已识别的正文保留在原始 JSON，并标记 `content_quality.version=1`、status及reason，发布日期证据不变。评分产物为NULL、`invalid_content`或`incomplete_content`、attempts=0，区别于有效0分及空正文；完成检查重新校验正文与状态，允许确定性的质量跳过结束批次。入库和补分边界再次核对正文，避免旧数值分绕过。正文质量跳过独立计数，不冒充有效评分。

只拦截明确样式，不能保证发现所有广告、SEO、错误页或付费墙。质量跳过不会自动反复抓取；原有腾讯等标题重抓路径仍保留。日期复核的投递仍受现有最多三次边界约束，不会把未评分记录标为交付成功。

## 紧凑发布日期

明确日期字段支持完整ASCII八位`YYYYMMDD`，用日历构造验证；非法日期、夹杂文字/更长数字不作此格式解析。与其他证据日期冲突时仍pending。此修复使`pubdate=20261006`与ISO日期一致时可通过，不忽略冲突证据。

## 摘要事实与归因

普通单条摘要与公积金摘要均在完整的批次固定业务system prompt后追加统一来源约束：不凑观点、不补推测、没有明确发言就省略观点段落。原有外部配置文档及提示词不改写；地区/业务类型JSON格式不变。

加入保守的匿名归因校验：摘要新增“受访者认为”“专家表示”等类别时，正文须存在该类别的明确发言结构；允许有限采访及时间修饰语。拒绝结果走现有有界失败/重试路径，不静默写入、不自动补做人物观点。短正文直接复制路径保持原文，不生成新归因。

这不是完整语义蕴含校验：已有说话人被误转述、具名人物的新观点及未知语言变体仍需内容质量评估。未增加第二个模型审核请求；本次没有调用真实付费模型，不能把离线通过等同生产摘要质量完全解决。
