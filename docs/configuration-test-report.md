## 本轮发现和修复

- 迁移工具原先会忽略自定义导入、函数及装饰器；现在只接受已知导入和原有纯函数，无法确认的源文件须先核对。
- 专用评分映射原先可误指向 User 模板；现在明确拒绝。
- 导入和恢复预览原先没有检查预期版本；现在与正式提交保持一致的冲突判断，正式写入仍再次检查。
- 非 ASCII 的 CSRF 令牌会触发 500；现在返回 400。
- 关键词重命名原先只移动专用提示词，没有移动规则评分；现在在同一新版本中同步保留。
- 后台启动的状态文件原先依赖当前目录；现在固定到项目输出目录，与子进程一致。
- 后台重评原先可能在另一个目录查找输出或启动脚本；现在查找、批次绑定和子进程工作目录一致，并拒绝非法日期。

首次执行的失败项中，另有测试夹具引号不匹配、旧路由成功返回码预期错误，以及子进程数据库导入未 mock 三项测试设置问题，均已修正。数据库连接尝试被离线防护拦截，没有连接生产服务。

## 代码审查后的 4 项修复

| 问题 | 修复及新增回归 |
| --- | --- |
| 调用源码中的覆盖可能在迁移时被静默忽略 | 7 项参数化测试覆盖评分、摘要、地域脚本中的提示词、接口和映射覆盖；另测动态模型赋值及内联消息修改，均要求拒绝。正向用例确认模型/请求参数常量调整及注释仍可迁移，提示词不变 |
| 重命名可能合并已删除主题的旧评分规则 | 删除无专用映射但有评分规则的主题后，重命名到其旧名称被拒绝，版本不变；同名编辑和改为新名称仍成功 |
| 摘要全量查询可能处理未绑定配置的历史主题 | 分别测试全量、单主题、旧版本续跑，只处理绑定的关键词；另测显式传入不存在的主题，在访问数据库和 LLM 前失败 |
| 提示词 ID 可能遮蔽设置、派生字段或凭据名称 | 对 12 个代表性保留名称分别测试现用/归档状态，保存全部拒绝且版本不变；合法自定义提示词可保存 |
