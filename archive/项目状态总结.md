## 🎯 使用方式

### 完整流程运行
```bash
# 处理昨天的所有关键词新闻
python main.py

# 处理指定日期的新闻
python main.py 2025-07-08
```

### Web界面查看
```bash
# 启动Web服务
python app.py

# 访问 http://localhost:5000
```

### 故障排查
```bash
# 查看最新错误
tail -20 output/error_log.txt

# 查看运行状态
tail -20 output/run_log.txt

# 搜索特定错误
grep "ERROR" output/error_log.txt | tail -10
```
