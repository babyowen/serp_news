定时任务配置

将以下脚本复制到宝塔面板的「计划任务 → Shell脚本」中，设置每天 0:30 执行。

#!/bin/bash
# === 新闻采集系统 - 每日定时任务 ===
# 宝塔面板: 计划任务 → Shell脚本 → 粘贴本脚本 → 每天 00:30

# 1. 项目目录（部署后改成实际路径）
PROJECT_DIR="{{ project_dir }}"

# 2. 进入项目目录
cd $PROJECT_DIR

# 3. 加载环境变量
set -a
source .env 2>/dev/null
set +a

# 4. 激活 Python 虚拟环境
source .venv/bin/activate

# 5. 执行流水线
python main.py >> $PROJECT_DIR/cron.log 2>&1

# 6. 退出虚拟环境
deactivate 2>/dev/null
